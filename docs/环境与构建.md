## 编译器

本机原无 C++17 编译器，2026-11-26 安装 MSYS2 到 `D:\msys64`（不动 C 盘，免管理员权限）。

| 项 | 值 |
|---|---|
| 编译器 | `D:\msys64\mingw64\bin\g++.exe` |
| 版本 | g++ (Rev7, Built by MSYS2 project) **16.2.0** |
| 目标 | x86_64-w64-mingw32 |
| 本地 shell 调用 | `PATH="/d/msys64/mingw64/bin:$PATH" g++ ...`（不加 PATH 时 cc1plus 找不到运行库） |

> 备选：`D:\dev c＋＋\Dev-Cpp\MinGW64\bin\g++.exe` 为 TDM-GCC 4.9.2，不支持 `-std=c++17`，仅在无其他工具链时降级使用。

## 构建命令

```bash
mkdir -p build
PATH="/d/msys64/mingw64/bin:$PATH" g++ -std=c++17 -O2 -o build/solver.exe src/main.cpp
```

提交 OJ 用单文件版本：`src/main.cpp` 自包含，无第三方依赖。

## 参考评测器

`tools/judge.py`（Python 3.13）为本项目的慢速参考实现 + 本地评测器：

- `replay` 模式：字面回放 `tests/samples/*.txt` 中的官方交互记录，用官方 ANS 校验参考实现本身。
- `run` 模式：驱动 `solver.exe` 跑一个世界，校验协议、对账答案与指令合法性，报告利润构成。

```bash
python tools/judge.py replay tests/samples/sample1.txt
python tools/judge.py run --world tests/worlds/demo.in --solver build/solver.exe
```
